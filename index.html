How does the model work?

This teaching model fits a simplified multilevel logistic regression to poll responses: it estimates a shared effect for each population type and a partially pooled state effect. It then predicts support for every type in each state and averages those predictions using that state's population proportions.

The default scenario is designed to make reach bias visible: older adults are more likely to respond, and support differs by age. Results vary with every draw. The model never uses the hidden true support to make its prediction. When a state has lots of respondents, the model has more evidence about that state’s distinctive level of support. When Juniper has only a few, the model relies more on patterns from elsewhere. That can help stabilize its estimate—but if Juniper is particularly unusual, the estimate may be pulled too close to the other states. The simulation is illustrative, not a full professional polling model; it does not model turnout or uncertainty intervals.

Five experiments to try

Draw a new poll after changing the settings. Repeat each experiment several times: one poll can give a misleading impression.

  1. Change the national sample size. Try a much smaller and then a much larger poll. How do the average errors for the raw poll and MRP change?
  2. Investigate tiny Juniper. Set its sample size to 4, then 12, and then try a much larger number. Across several polls, how close are its raw and MRP estimates to the truth? Does more local data help?
  3. Change who answers. Move the reach slider toward younger adults, then older adults, then the middle. How does the direction and size of reach bias affect the two estimates?
  4. Make a state unusual. Give one state a large positive or negative support shift, keeping its sample small. Does the model pull its estimate too close to the other states? What happens when you increase that state’s sample?
  5. Experiment with pooling. Compare low and high pooling strength with the same population and sample settings. Which states benefit from borrowing more information, and which might suffer?
